## HTML para o eu do futuro

HTLM o que sigmifica?

HTML significa hyper text mekup language

É uma linguagem de marcação usada para estruturar e formatar conteúdo em páginas web. Ao contrário das linguagens de programação, HTML não realiza operações ou cálculos lógicos. Em vez disso, define o layout e a organização dos elementos em uma página web, como texto, imagens, links e multimídia.

## CSS o que é?

O CSS (Cascading Style Sheets) é a linguagem usada para definir a aparência visual de páginas web, separando o conteúdo HTML da sua apresentação.
